## Featured Security Projects

### Linux Security Audit Framework

A modular security auditing tool designed to evaluate Linux systems against **CIS benchmark security controls**.
The framework performs automated security checks across system configuration, authentication controls, filesystem security, and logging.

### Web Security Testing Toolkit

A collection of tools designed to assist penetration testers in identifying common **web application vulnerabilities** such as insecure HTTP configurations, authentication weaknesses, and API security issues.

### DevSecOps Security Pipeline

A CI/CD pipeline integrating automated **security testing into the software development lifecycle**, including static analysis, secret detection, container security scanning, and infrastructure-as-code validation.

### Threat Modeling Toolkit

A structured toolkit supporting **security architecture reviews and threat modeling exercises** using STRIDE and risk-based analysis approaches.
